# PEM-Fuel-Cell-CFD-Simulation-using-ANSYS-Fluent
This project presents a Computational Fluid Dynamics (CFD) analysis of a Proton Exchange Membrane (PEM) Fuel Cell using ANSYS Fluent. The study focuses on thermal behavior, reactant transport, pressure distribution, and electrochemical performance inside the fuel cell.

The simulation investigates:

Temperature distribution
Oxygen and hydrogen transport
Pressure variation
Flow characteristics
Thermal stability of PEM fuel cell operation
